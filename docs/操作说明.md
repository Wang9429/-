# 操作说明（V1.6 系统业务原型）

页面标题：海油工程｜穿透式监管平台。本说明供业务确认与实施调研，不是删减功能范围的讲解脚本。

## 启动与身份

1. `npm run preview`，打开预览入口。
2. 顶栏切换用户。默认「总部监管人员A」。切换后组织范围、抽屉和 AI 上下文一并重建。
3. 「数据说明」集中写明合成样例性质。重置入口在「系统配置 → 数据与运行」。

## 路径一：投资执行到超概算

1. 综合总览点击 84% 卡片，打开组织穿透。
2. 左树到下属三级单位 A1 / 基地能力提升项目，见 80%；下属二级单位 B / 设施技术改造项目见 90%。
3. 右侧查看分子分母。关闭浮层后背景组织不变。
4. 打开 FA-P001 计算依据：预计完工投资 11800、有效概算 10000、偏差 18%，五项构成可追溯，进入 R01。

## 路径二：转固后资产

1. 固定资产投资首页点击「运营及后评价」，子视图默认「资产运营」。
2. 下区五数建设实施为 2/1/1/0/0，运营及后评价为 2/1/1/0/1。
3. 打开专用装备 A（AS001）：2025 年四季度 48%、2026 年一季度 46%；4–6 月 47%、45%、40% 为月度走势。R02 整改逾期。
4. 可追溯来源项目 FA-P002。总体利用率 60% 不遮蔽 AS001 异常。

## 路径三：股权收益及资金

产业能力股权投资项目 EQ-P001：到期出资履约 80%、缺口 600；分红回收 40%、未收 120。会计收益 200 与现金到账 80 分列。资金领域打开同一 R03/R04。

## 路径四：国际事件及情景

钢材 +10%、运费 +25%，增量 48+100=148 万元，情景毛利率 11.26%。工程基础预测 12% 不被覆盖。真实历史事件日期与样例行情分别标识。

## 路径五：支付核查与可选闭环

付款 P-PAY001：实付 1200、有效批准 800、可支付上限 2000，超批准 400。资金、工程、国际化打开同一 R07。

可选闭环：

1. 切换「二级单位A管理人员」，认领 R07，核查确认需整改。
2. 在「整改材料」阅读《付款审批控制核查及措施执行记录》，点击「采用并保存为新记录」，再提交整改。
3. 切换「总部复核人员B」，采用《付款审批控制整改复核记录》后复核通过。原办理人不能自审。
4. 未关闭 8→7，资金/工程/国际化各减 1。原始 1200/800/2000 与差额 400 不变。

## 路径六 / 七

产权：JV001 同有效期批准 60%、工商 60%、台账 55%，R08 待核实。工程：ENG-P001 收入 20000、成本 17600、基础毛利率 12%；并行阶段可点。

## 系统配置

侧栏底部进入。六个 Tab 均可查看列表/详情；监测规则可试算「预计完工投资偏差关注」（10% 命中 FA-P001 18%，25% 两者不命中），发布不覆盖历史 R01。

## AI分析

右下浮动入口。标注「预置分析 · 未连接模型服务」。支持解释指标、梳理命中、对比材料、建议核查。不跨权限、不自动关闭事项。
