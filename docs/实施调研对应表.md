## 以执行率 84%→项目 80% 为例的具体问题

1. 哪个系统保存项目年度计划、月度分解和调整版本，谁维护有效版本。
2. 「完成投资」采用什么口径，与会计成本、合同计量及资金实付如何区分。
3. 两类数据是否都有统一项目编号和所属单位，二级直管项目如何归属。
4. 可按什么频率获得数据，历史更正如何传递，能否提供脱敏样本。
5. 抽屉中的分子分母未来通过接口明细、平台副本还是跳回源系统查看。

字段业务名可先定义，正式系统字段名和接口映射待核实。确认后的输出应包括指标到来源字段的映射及更新频率，不能把本表自行标成已确认。
