# Cursor执行指令 资金与产权穿透式监管专项改版

在当前海油工程穿透式监管平台工程内，按本包FP-20260916-R2版增量实现资金管理和产权管理，并同步系统配置。它们是同一监管平台的两个子领域。请连续完成需求适配、开发和验收，不另建网站。

先阅读README，再阅读01主业需、02/03完整场景规则、04配置迁移和05产品参考；00是包含全部80个子场景的单文件完整阅读版，06为本指令。若旧包与R2不一致，以R2为准。JSON是需求目录，不是可直接替换现有seed的文件。

一、固定改造边界

综合总览保持已确认的布局、标题、指标选用和交互；资金、产权办理与配置引起的正常总览数据联动保留。其他领域不扩大改造。沿用已有蓝色系统样式、指标抽屉、详情浮层、权限和整改工作台。修改前记录当前提交、已有场景/规则/指标ID及迁移映射，不清空用户配置、账户台账或历史办理记录。

二、资金管理按监管视角重构

上区“主体经营与财务状况”：盈利能力、资产负债、资金流动性分类，先列直属二级单位，选单位联动上下区域；展开按钮只展开真实下级。点击指标在抽屉内下钻，不改页面范围。财报数据、资金余额和项目业务数据分别取正确来源、期间与口径；比例不平均，项目无报表不硬造资产负债率。

下区“资金专题监管”：账户管理、资金收付、融资与担保、资金运作、专项资金、经营风险。专题有业务规模、规则执行、待核查和整改结果，可查看全部对象、命中对象和未评估对象。账户/交易/合同分别计数。借入属于融资，出借属于资金运作。

必须实现主体或指标→业务对象→合同/审批/流水依据→规则命中→核查整改的完整路径；正常业务也能打开明细。本平台展示源业务控制结果，不新增正式支付、融资、开户等办理审批。

三、产权管理按监管视角重构

上区“法人及股权全景”：纳管法人、控股及实控企业、参股企业、在办产权事项；清单与股权图可切换。同一法人多父持股只计一户，分支不算法人；海工本体、控制、参股及待核实口径按主业需。直接股比、穿透权益和实际控制依据分开。

组织范围切换联动全页；图谱单法人点击聚焦档案及下区相关事项，并显示当前法人，四张范围统计仍保持当前组织范围。清除法人选择恢复该组织全量；展开图谱和点击关系边不扩大授权。

下区为产权交易流转、产权登记、标识与名称资质、股权与控制权四个专题。交易采用横向肩形监管节点，按转让、无偿划转、增资、资产转让、上市股份适配实际流程和例外。点击环节查看适用场景、命中对象与整改情况；原业务进入下一阶段不隐藏前一阶段未关闭问题。

四、打通两个领域

产权法人/交易详情可查有权查看的借款、担保、交易价款；资金付款/担保详情可回查相关法人关系及产权事项。复用法人、合同义务、交易和主事项ID，不复制金额和整改。跨域进入时保留期间、截至日及返回位置，不修改全局范围、不扩大授权。

五、同步配置

保留资金11类40子场景、产权10类40子场景原文和建议语义，按现有ID兼容迁移。同步专题/节点映射、规则执行器、指标、AI任务、数据来源及权限，配置页面保留新增、编辑、启停、试算和发布等有效操作。业务页面与配置读取同一目录。

新增定义默认草稿；首批路径完成执行器或专业核查流程、数据和验证后发布为可展示版本。自动监测、规则辅助人工、专业核查与运行能力分开。未实现规则不能因发布就显示已运行。两个个人名义资金/账户补充场景仅为待确认草稿，不自动启用。

保留CASH-R01/R07实付1200、批准800、业务上限2000的事实及日志；保留产权批准60%/登记60%/台账55%的来源差异，不直接改判登记违规。新版本不覆盖历史评估，不允许通用发布绑定固定资产EAC执行器。迁移重复执行无新增重复记录。

六、AI与展示

AI读取当前主体、业务对象、期间及有权证据；不得仍绑定FA-P001。缺模型时如实显示预置分析能力。页面不加介绍性副标题或概念说明；停用指标不留下空卡。金额单位正确，场景长名可读，1440/1280无整页横溢，浮层逐层关闭与返回位置保持。
