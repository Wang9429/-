## 2. 部署包里有什么

应用保持现有 Next.js 与全部交互，改为 `output: "standalone"` 的 Node 正式服务，前面用 nginx 终止 TLS。页面、接口、字体、脚本、图片均随站点构建，不引用 Google Fonts、jsDelivr、unpkg，也不指向 localhost 或隧道。

| 产物 | 生成方式 | 用途 |
| --- | --- | --- |
| 源码部署包 `dist/cnooc-supervision-cn-src-<短提交号>.tar.gz` | `npm run pack:cn` | 拷到国内主机后 `docker compose build` |
| 预构建包 `dist/cnooc-supervision-cn-standalone-<短提交号>.tar.gz` | 同上 | 国内主机已有 Node 20+ 时，解压后 `./start.sh` |
| `Dockerfile` + `deploy/docker-compose.yml` + `deploy/nginx.conf` | 仓库内 | 国内云主机正式编排 |
| `deploy/install-on-ecs.sh` | 仓库内 | 在 ECS/CVM 上一键拉起（需先放证书，或 `MODE=bootstrap` 申请证书） |
| `deploy/check-mainland-access.sh` | 仓库内 | **在中国大陆普通网络**上检查 HTTPS 站点 |

打包命令（在仓库根目录）：

```bash
npm ci
npm run pack:cn
```

访客**不需要** Cursor、GitHub、Vercel 账号。应用内原有角色切换、授权范围与数据范围控制保持不变（浏览器本地状态，不是公司 SSO）。

`/api/source-package` 在正式服务中默认关闭（返回 404），避免依赖 Agent 的 `/tmp` 路径。

## 3. 需要你提供或开通的资源

缺任一主项，都无法完成「固定 HTTPS + 大陆可访问 + 关电脑后仍可用」。

### 必需要你提供

1. **中国大陆地域云主机**（三选一即可）
   - 阿里云 ECS 或轻量应用服务器（推荐地域：华北2 北京 / 华东1 杭州 / 华南1 深圳，按公司属地选）
   - 腾讯云 CVM 或轻量
   - 公司已有演示环境：一台可 SSH 的 Linux 主机，或已有 nginx/K8s Ingress 的命名空间
2. **SSH 登录方式**：公钥或堡垒机；当前 Agent **没有**任何国内主机密钥，不能代你登录。
3. **已完成 ICP 备案的域名**，或公司已备案主域下可解析的子域名（例如 `supervision-demo.example.com`）。
   - 在大陆服务器上对公众提供网站服务，绑定域名通常需要备案。未备案域名不能作为本轮验收地址。
4. **DNS 解析权限**：A 记录指向该主机公网 IP。
5. **安全组 / 防火墙**：放行 **80、443**；SSH 仅对运维网段。
6. **TLS 证书**（三选一）
   - 阿里云 / 腾讯云免费 DV 证书（推荐，控制台申请后下载 `fullchain.pem` + `privkey.pem`）
   - Let’s Encrypt（`certbot`，主机需能被公网 80 访问）
   - 公司已有证书

### 可选

- 国内 Docker 镜像加速（阿里云容器镜像服务个人实例、DaoCloud 等），便于拉取 `node` / `nginx` 基础镜像。
- 若走公司统一入口：把 `deploy/nginx.conf` 的反向代理段并入现有 nginx，上游 `127.0.0.1:43917`。

### 不需要

- 数据库、Redis、对象存储、短信、模型 API
- Cursor / GitHub / Vercel 登录
- VPN

## 4. 预计费用（公开参考，以下单控制台为准）

本原型无数据库、无对象存储、无按调用计费的 API，费用几乎只来自 **云主机 + 带宽 + 域名/证书**。数字为 2026 年公开活动价/标价量级，**不是报价单**。

| 方案 | 规格（建议） | 参考费用 | 说明 |
| --- | --- | --- | --- |
| 推荐：阿里云 ECS 通用算力 u1 | 2 核 4G、5M 固定带宽、80G 盘、大陆地域 | 活动价约 **199 元/年**（企业实名，含带宽与盘） | 演示并发很低，足够 |
| 备选：阿里云轻量应用服务器 | 2 核 4G 档 | 活动价约 **百元级/年** 至约 **298 元/年** | 带独立 IP，适合演示 |
| 备选：腾讯云轻量 / CVM | 2 核 4G、大陆地域 | 同年活动常见 **百元级～三百元级/年** | 与阿里云二选一即可 |
| 无活动、按量/包月 | 2 核 4G + 5M + 40G | 大约 **50–80 元/月** 量级 | 短时演示可用，长期不如年付 |
| 域名 | 已备案域名的子域 | **0 元** | 只需解析 |
| 新购域名 | `.com` / `.cn` | 大约 **50–80 元/年** | **另需 ICP 备案周期**，不能当天验收 |
| 证书 | 云厂商免费 DV / Let’s Encrypt | **0 元** | 不要买付费通配符，除非公司统一要求 |
| 备案服务号 | 阿里云/腾讯云 | **0 元** | 首次备案常需 **数个工作日到数周**，阻塞域名上线 |
| 本 Agent 代为值守 | — | **做不到** | 无国内云权限 |

**最低可上线组合（已有备案域名时）：** 一台 2 核 4G 大陆主机 + 免费证书 ≈ **199 元/年** 量级。  
**若没有备案域名：** 费用不是主因，**备案时间**才是上线路径上的硬门闩。仅用公网 IP 提供 HTTP 不符合本轮「固定 HTTPS 域名」验收。

## 5. 在国内云主机上的部署步骤

以下以 **阿里云 ECS + 已备案域名** 为例。腾讯云把「安全组 / 轻量防火墙」换成对应控制台即可。公司演示机从第 3 步开始。

### 5.1 控制台

1. 地域选中国大陆（不要选香港、新加坡）。
2. 镜像：Alibaba Cloud Linux 3 或 Ubuntu 22.04。
3. 规格：2 核 4G；系统盘 ≥ 40G。
4. 分配公网 IP；带宽建议 5Mbps 固定。
5. 安全组入方向：22（运维）、80、443。
6. 域名 DNS：`A` 记录到该公网 IP，等待生效。

### 5.2 上传部署包

把 `cnooc-supervision-cn-src-<短提交号>.tar.gz` 拷到主机（scp / 堡垒机），例如：

```bash
sudo mkdir -p /opt/cnooc
sudo tar -xzf cnooc-supervision-cn-src-<短提交号>.tar.gz -C /opt/cnooc --strip-components=1
cd /opt/cnooc
```

### 5.3 证书

将 `fullchain.pem`、`privkey.pem` 放到 `deploy/certs/`。  
若还没有证书，可临时：

```bash
sudo MODE=bootstrap DOMAIN=你的已备案域名 EMAIL=运维邮箱 bash deploy/install-on-ecs.sh
# 按脚本提示用 certbot 写入 deploy/certs/ 后：
sudo bash deploy/install-on-ecs.sh
```

未切回 HTTPS 前，**不能**作为本轮验收地址。

### 5.4 启动正式服务

国内网络建议先写 `deploy/.env`（可从 `deploy/env.example` 复制），把基础镜像换成当时可用的国内源，例如：

```bash
NODE_IMAGE=docker.m.daocloud.io/library/node:22-bookworm-slim
NGINX_IMAGE=docker.m.daocloud.io/library/nginx:1.27-alpine
NPM_REGISTRY=https://registry.npmmirror.com
```

然后：

```bash
sudo bash deploy/install-on-ecs.sh
```

或手动：

```bash
cd /opt/cnooc/deploy
sudo docker compose --env-file .env up -d --build
```

服务监听：容器内 Node `43917`，对外 **443**。关笔记本电脑、关 Cursor 后，只要这台 ECS 在，站点就在。

### 5.5 不用 Docker 时

解压 `cnooc-supervision-cn-standalone-<短提交号>.tar.gz`：

```bash
export HOSTNAME=0.0.0.0 PORT=43917
./start.sh
```

再由主机或公司 nginx 按 `deploy/nginx.conf` 反代到 `127.0.0.1:43917`，证书仍挂在 nginx。

## 6. 验收必须在中国大陆网络做

在 **不开 VPN** 的大陆宽带或手机网络上：

```bash
bash deploy/check-mainland-access.sh https://你的已备案域名
```

浏览器再手工做：

| 步骤 | 期望 |
| --- | --- |
| 地址栏直接打开 `/overview` | 综合总览出现，无需任何第三方账号 |
| 刷新 | 布局与数据仍在（办理状态在浏览器本地） |
| 打开 `/funds` | 资金上区指标与下区专题可点 |
| 打开 `/property-rights` | 产权上区法人户数可进详情，下区专题可点 |
| 打开 `/settings` | 系统配置六 Tab 可切换；角色与数据范围控制仍在 |
| 开发者工具 Network | 脚本/字体/图片均为本站 HTTPS，无 localhost、无隧道、无 Google 字体 |

**本 Agent 出口不是中国大陆用户网络，不能代替上述检查。** 在国内主机上线之前，上表全部为 **待验证**。
