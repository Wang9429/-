# 本轮修改包使用说明

版本：FP-20260917-R3.2。

把本文件夹放进现有Cursor项目的docs或requirements目录，先让Cursor读取00指令，再按01业需实施，02/03用于逐项补齐覆盖。

| 文件 | 用途 |
|---|---|
| 00_Cursor本轮执行指令_R3_2.md | 可直接粘贴给Cursor的完整指令 |
| 01_资金产权本轮增量业需_R3_2.md | 展示、切换、规则能力、统计与历史、迁移、16项验收及发布要求 |
| 02_一级场景可执行覆盖计划_R3_2.md | 资金11项、产权10项的原名、候选已有子场景和具体可执行路径 |
| 03_一级场景可执行覆盖参考_R3_2.json | 同一覆盖计划的结构化实施参考，含产权导航要求 |

本包是本轮增量业需，不是应用源码或可直接覆盖应用配置的数据种子。JSON中的rule_id尚待现工程核对，null不表示删除既有规则；不可整份导入覆盖原配置。

本版替换R3.1中“业务页显示未启用子场景以便全目录可见”的要求：业务执行区仅展示有效启用且可执行的规则，默认交付21个一级场景均有实际可用能力。默认产权交易显示适用流程，切到登记等专题后隐藏交易流程并撤销其查询影响。

本轮补做「监管场景详情业务化展示」：资金/产权场景详情、规则详情、监测对象、命中依据及专业核查改为中文核验表；S039 须分列该笔批准800、实付1200、超出400、上限2000；产权持股60/60/55分行带来源和基准日；专业核查展示材料与结论，待核查不得写成已确认违规。仅改展示映射，不改计算与 ID。详见 `01` 第10节。

综合总览设计、资金指标与适用趋势、产权无常显公式/无趋势、组织权限、历史及正确金额继续保留。资金11项和产权10项原始一级名称、80条子场景ID不变。本包不对当前公网功能作已验收声明。

原R3/R3.1中与本版不冲突的条款继续有效；工程内的需求文件也应同步更新，不必重复导入全部旧包。

最终只需一个整体入口：https://wang9429.github.io/-/overview/ 。从侧栏进入资金、产权与系统配置查看同一构建的更新。
