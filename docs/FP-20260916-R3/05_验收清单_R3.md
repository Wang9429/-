# FP-20260916-R3受影响路径验收清单

本清单供Cursor实现后执行。当前仅是验收要求，不代表系统已经通过。实际结果写入工程验收记录，记录实现提交、运行构建、账号、组织、期间、截至日、操作与结果。沿用有效既有测试，不为凑数量增加镜像实现的断言。

## 一、资金指标和趋势

| 编号 | 实际操作 | 通过条件 |
|---|---|---|
| R3-01 | 依次选择资金三个分类 | 各类最多4张指定主卡；首页没有重复完整单位表；有效指标小趋势按适用条件显示 |
| R3-02 | 盈利能力→营业收入详情→展开指标切换 | 只出现盈利能力有效指标，无资产负债、流动性及其他领域项；修改显示名称不影响分类过滤 |
| R3-03 | 分别从资产负债率、可用资金进入详情 | 候选仅本分类有效项；不沿用上一次其他分类候选缓存 |
| R3-04 | 总部→二级单位→实际末级→适用对象 | 与总览同ID同层级；树、当前值、趋势、比较、明细和依据同时更新；无虚构中间层 |
| R3-05 | 在无独立报表节点展开下级 | 保留节点及真实状态，可继续看合法下级；不填0、不复制上级报表 |
| R3-06 | 在项目或账户对象切换同分类但不适用的新指标 | 返回当前合法根内最近适用单位，保留期间/截至日；不回越权总部、不出现undefined |
| R3-07 | 核对上半年收入主卡和月份小图，再开详情 | 累计值与月发生额标签清楚，覆盖完整时月值可核对累计；首页与详情默认同序列同点值 |
| R3-08 | 核对账户/债务余额和比率趋势 | 余额来自各期末；比率各点由同口径分子分母计算；不累计月余额、不平均比率 |
| R3-09 | 打开净资产收益率及依据 | 利润和平均净资产匹配，显示实际期间不默认年化；仅半年数据不生成月度ROE；季度图有独立季度数据 |
| R3-10 | 查看无历史/单点/不适合趋势的有效指标 | 不画虚线或空图框，当前卡和穿透仍可用；数据缺口不补0，不随机生成 |
| R3-11 | 更改截至日、切到缺历史快照日期 | 图无未来点，当前值遵守原历史数据可用性；新增月末样例不伪造任意日财务快照 |
| R3-12 | 检查负基数同比、比率变化、报表范围不同样例 | 不误报增长率；百分比差值用百分点；不可比不连为可比走势，合并与个别范围可辨 |
| R3-13 | 停用一项指标或关闭其首页趋势，再刷新 | 停用隐藏主卡/候选；关闭趋势只去图保留指标；存储刷新仍生效，不影响其他指标独立开关 |
| R3-14 | 下钻、切指标后关闭多层浮层 | 背景筛选不变，逐层返回原入口与滚动位置；身份变化清理越权旧内容 |

## 三、产权导航与穿透

| 编号 | 实际操作 | 通过条件 |
|---|---|---|
| R3-21 | 核对40条场景与10一级目录 | 四专题主归属正确；旧日常专题不再写入主环节；原ID/规则/历史保留 |
| R3-22 | 产权交易→登记→名称资质→股权控制→返回交易 | 只有交易有经济行为和流程；其他直接场景表；不存在残留交易阶段过滤或旧场景混入 |
| R3-23 | 切换产权转让、无偿划转及已实现其他模板 | 使用各自适用模板；无偿划转无价款逾期；上市股份不套非上市定价公式；全部类型不展示伪统一进度 |
| R3-24 | 同一法人下选择两笔不同交易、再取消选择 | 两笔各有进度；不把企业整体标为一个阶段；环节过滤不改上区整体指标 |

| R3-26 | 产权四专题各走一代表路径 | 交易S006/S035、登记S028、名称资质S025、控制S032或等价已有路径有对象/材料/核查；不是仅目录 |
| R3-27 | 从登记专题与交易末端打开同一登记义务 | S027/028/039须满足具体关联条件；同义务同case，汇总不重复；S029/040不无条件挂交易末端 |
| R3-28 | 查看产权卡片趋势及历史清单 | 有有效历史才绘图，快照/重建点可核对；静态股比或控制结论不伪造趋势 |
