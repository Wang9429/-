#### 融资与担保｜CASH2-S012 担保实施超出已批准担保额度

- 处理方式：自动监测；补齐代表性路径，是否已有执行能力须在当前工程核实。

### 5. 跨环节控制与去重

- PTY2-S014 决策人员回避以实际审议表决及已核实回避义务为依据，主归决策审批；PTY2-S015 中介回避主归审计评估，仅有适用义务与实际承办记录时关联交易实施。二者不能互相替代。
- PTY2-S012 信息矛盾可发生于决策材料、审计评估提供资料或交易披露；由材料版本和实际使用记录匹配环节，不将整个一级场景不加区分挂满流程。S013 仍需合法取得的独立干预证据并由专业人员判断。
- PTY2-S035 报告有效期在实际使用节点核验。已关联多个用途可以多个环节查看同一问题；没有明确适用期限就不得编造统一期限。
- PTY2-S027、S028、S039 主归产权登记，仅交易引发该法人具体登记义务时关联登记变更及归档。S029 证表真实性、S040 证表转借是日常使用控制，不统一搬到交易末端。
- S025 名称字号授权异常只有本笔退出等事件触发明确处置义务时才关联末端；S024 标识程序只有具体上市路由明确前置要求时才关联方案权限核验。
- S030/S031 的交易条件路由只作关联依据入口，不凭关联把治理专业核查结果复制成新的交易命中。
- 列表按 scenario_id 去重；评估按照原 evaluation_id、对象类型及 object_id 保留；同一问题跨专题复用原 case_id，未关闭整改统计按唯一 case_id 去重。不同义务、不同对象、不同检查时点的独立问题不因同一企业而合并。
- conditional_routes 的 required_match_keys 是最少业务关联键要求，由 Cursor 映射到现有模型；不得为满足筛选虚构关联键事实。legacy_stage 不参与新版业务筛选。

### 6. 每专题至少一条可操作路径

#### 6.1 产权交易：权限核验与价款联动

保留已实现 PTY2-S006 权限检查，点击对象能查看适用授权文件、边界口径和批准记录。补齐或复用 PTY2-S037 路径：选择存在价款的产权转让 → 选签约结算与交割 → 场景执行情况打开到期价款核查 → 同一合同下查看有效付款计划、到期日、应收金额、已到账资金和未收余额 → 资金明细浮层或有返回上下文的领域跳转 → 待核查事项认领、结论、整改及独立复核。正常足额到账样本也能查看依据。无偿划转不得进入该价款场景。

#### 6.2 产权登记：具体变动义务

选择产权登记 → PTY2-S028 → 打开具体法人及变动事件 → 核对是否构成产权变动登记义务、起算事件、适用期限、申报及受理状态 → 形成核查结论。及时申报后受理中与未申报分别显示。既有批准 60 / 登记 60 / 台账 55 仅作数据一致性待核实，不单凭差值判登记逾期。若该登记义务由某笔交易产生，两处引用同一对象、同一评估及同一事项。

#### 6.3 标识与名称资质：名称字号授权核查

选择标识与名称资质 → 启用 PTY2-S025 的规则辅助人工路径 → 查看法人登记名称、字号管理主体、授权文件、被授权主体、有效期及实际使用记录 → 人工确认材料完整性与适用要求 → 记录“授权有效／资料待补／需进一步核查／确认需整改”等有依据的结论并办理。至少提供一条授权有效、核查结论正常的样本；如提供异常样本，使用合成资料说明具体已过期授权及适用处置义务，不因名称相似自动命中。此处无须接入工商实时系统或新增自动执行器。

#### 6.4 股权与控制权：治理权利核查

选择股权与控制权 → 保留 PTY2-S032 已有专业核查 → 从 LE-CTRL 等当前样本打开章程协议、应派和到任记录及权利受阻材料 → 认领专业核查 → 有权人员记录结论并关联整改 → 独立复核。股比、应派席位、实派席位和实际权利分别展示，不能由股比或席位差值自动认定控股不控权。

每条路径都要提供查看正常记录的能力、权限校验、阶段或专题上下文恢复，以及按截至日还原的办理记录。保留原待核查与未关闭整改统计界限；不要为演示闭环重置或改写历史事实。

### 7. 配置、迁移与验收

系统配置编辑表单展示一级场景、主专题、主环节、适用业务类型、适用对象和条件关联。非交易主专题的主环节为空；旧 stage 原值存为 legacy_stage 只供溯源。改变映射只改变当前目录归属，不能把既有命中、证据及办理责任改写成新版本。

验收至少覆盖：四专题各有可用路径；选择非交易专题无流程条；无偿划转不出现价款逾期；信息披露和回避按具体角色与材料匹配；S027/028/039 关联条件生效且跨专题只记同一事项一次；S029/040 未无条件进入交易末端；法人筛选可清除；选阶段不改上区指标；场景主表靠前且不再单设大块“当前环节”。
