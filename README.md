# 海油工程穿透式监管平台（系统业务原型）

按 V1.6 业需在现有工程上增量改版的可交互系统业务原型，用于领导展示、业务需求确认及科技信息部实施调研。

页面标题为「海油工程｜穿透式监管平台」。主体、人员、金额、交易、汇率、行情和分析为**合成样例**，用于功能验证，不代表海油工程真实经营数据。真实历史事件日期与样例行情分别标识。

## 运行方式

```bash
npm install
npm run preview
```

打开 http://127.0.0.1:43917 ，默认进入综合总览。

| 命令 | 说明 |
| --- | --- |
| `npm run preview` | 生产构建并启动（端口 43917），推荐预览方式 |
| `npm run serve` | 常驻服务：缺少构建产物时先构建，进程退出后自动拉起 |
| `npm run dev` | 开发服务。若反向代理拦截 HMR WebSocket，页面可能无法交互，改用 preview |
| `npm run build` / `npm start` | 分步执行生产构建与启动 |
| `npm run lint` | ESLint |
| `npm run verify` | 口径自检：指标、阶段与五数对照种子预期值 |

业务办理状态保存在浏览器 `localStorage` 键 `cnooc-supervision-business-v16`；用户、规则草稿等配置保存在 `cnooc-supervision-config-v16`。在「系统配置 → 数据与运行」分别执行「重置业务办理状态」和「重置配置」。前者不清除用户配置。

## 技术栈

Next.js 16（App Router）、React 19、TypeScript、Tailwind CSS 4。无外部数据库与后端服务。

## 本版能力

- 七个业务入口 + 侧栏底部「系统配置」；顶部监管工作台汇聚待核查、整改、复核。
- 综合总览默认四指标：固定资产投资计划执行率 84%、未关闭 8、高风险 4、逾期整改 1。
- 指标卡打开组织穿透浮层；计算依据绑定当前指标、对象、期间，不串用 EAC 公式。
- 固定资产等流程领域用横向肩形箭头联动下区五数；资金用专题，国际化用事件/地区。
- 右下「AI分析」为预置分析，未连接模型服务。
- 系统配置六 Tab：用户与权限、监管场景、监测规则、指标管理、AI分析设置、数据与运行。
- 本地身份切换验证授权：单位 A 看不到单位 B；配置管理员无业务数据；独立复核不得自审。
- R07 提供合成整改/复核材料，须办理人显式采用后另建记录；闭环后 8→7，资金/工程/国际化同步。

## 数据与口径

- 业务截至日固定 2026-06-30，默认期间 2026-01-01 至 2026-06-30。金额默认万元人民币。
- 恢复种子后未关闭 8 件（红 4、黄 4；待核查 5、整改中 3、逾期 1）；R09 已排除。
- 总部执行率 8400÷10000＝84%；FA-P001 4800÷6000＝80%；FA-P001 EAC 偏差（11800−10000）÷10000＝18%。
- 覆盖规划候选不进入应评估分母，不在业务页显示为「数据不足」。
